Almacenamiento local (Estado Actual y Futuro)

Local Storage (Current and Future State)

Actualmente, el sitio web no guarda información de la sesión. Sin embargo, para garantizar la máxima transparencia en futuras funciones:

Currently, the website does not save session information. However, to ensure maximum transparency in future features:

  • Sin base de datos centralizada: No centralized database: No contamos con servidores donde se almacenen perfiles de usuario, contraseñas ni datos personales. We do not have servers where user profiles, passwords, or personal data are stored.
  • Procesamiento de API Keys (Próximamente): API Keys Processing (Coming Soon): Cuando se integre la función de lectura de API Keys de GW2, la clave se guardará únicamente en la memoria local de tu propio navegador (localStorage). When the GW2 API Key reading feature is integrated, the key will be stored only in the local memory of your own browser (localStorage).
  • Control total del usuario: Total user control: La clave API nunca saldrá de tu navegador hacia ningún servidor externo que no sea la API oficial de ArenaNet. Podrás borrarla en cualquier momento limpiando la memoria caché de tu navegador o usando el botón de "Cerrar sesión / Eliminar clave" que se incluirá en la interfaz. The API key will never leave your browser to any external server other than the official ArenaNet API. You can delete it at any time by clearing your browser's cache or using the "Log out / Delete key" button that will be included in the interface.
